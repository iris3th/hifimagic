Use {artist} and {album}. HifiMagic reads only year, genre, summary, artwork and link fields from the JSON response. No credentials may be stored in the URL.

AllMusic has no public API and Last.fm is deprecated and key-based, so neither is built in. A local proxy can be used as the custom endpoint.

Local data backup

Download a zip of your player address, playlists, favourites, library index, artist and album notes, radio data, and interface preferences. Restore replaces those files with the ones in the zip.

Everything stays on this computer. No account or cloud service is used. If a restored backup changes the player address, restart the app to connect to it.
